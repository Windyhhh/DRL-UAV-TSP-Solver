# 基于深度强化学习的无人机旅行商问题项目详细使用说明

## 项目概述

本项目实现了基于深度强化学习的无人机旅行商问题(TSPD)求解方法，使用Actor-Critic(A2C)算法和注意力机制来解决无人机与卡车协同配送的优化问题。

## 项目结构

```
├── main.py                 # 主程序入口，负责训练和测试
├── utils/                  # 工具模块
│   ├── options.py          # 参数配置文件
│   ├── agent.py           # A2C强化学习智能体
│   ├── env.py             # TSPD环境定义
│   ├── env_no_comb.py     # 简化版环境
│   └── utils.py           # 通用工具函数
├── model/                  # 神经网络模型
│   ├── AttentionModel.py  # 注意力模型
│   ├── graph_encoder.py   # 图编码器
│   └── nnets.py          # Actor-Critic网络
├── data/                   # 测试数据集
├── trained_models/         # 预训练模型
│   ├── n11/              # 11节点预训练模型
│   ├── n15/              # 15节点预训练模型
│   ├── n20/              # 20节点预训练模型
│   ├── n50/              # 50节点预训练模型
│   └── n100/             # 100节点预训练模型
├── results/               # 输出结果
├── logs/                  # 日志文件
├── images/                # 示例图像
└── 使用说明文档.md          # 本文档
```

## 脚本功能详解

### 1. 主程序脚本

#### `main.py`
- **功能**：项目的主入口文件
- **作用**：
  - 解析命令行参数
  - 初始化数据生成器、环境、神经网络模型和智能体
  - 根据配置执行训练或测试
  - 加载预训练模型
- **使用方法**：
  ```bash
  python main.py --train=True    # 训练模式
  python main.py --train=False   # 测试模式
  ```

#### `visualize_solution.py`
- **功能**：解决方案可视化
- **作用**：
  - 可视化TSP问题实例
  - 绘制最优路径
  - 生成图像结果
- **使用方法**：
  ```bash
  python visualize_solution.py
  ```

#### `visualize_tsp_drone.py`
- **功能**：专门用于TSPD问题的可视化
- **作用**：
  - 显示卡车和无人机的路径
  - 可视化配送过程
  - 生成SVG格式的解决方案图

### 2. 工具模块

#### `utils/options.py`
- **功能**：参数配置文件
- **包含的主要参数**：

##### 数据生成参数
- `--n_nodes`: 节点数量（默认11）
- `--R`: 无人机电池续航时间单位（默认150）
- `--v_t`: 卡车速度 m/s（默认1）
- `--v_d`: 无人机速度 m/s（默认2）
- `--max_w`: 无人机最大载重（默认2.5）
- `--batch_size`: 训练批次大小（默认100）
- `--n_train`: 训练轮数（默认1,000,000）
- `--test_size`: 测试实例数量（默认100）

##### 神经网络参数
- `--embedding_dim`: 输入嵌入维度（默认3）
- `--hidden_dim`: 隐藏层维度（默认256）
- `--rnn_layers`: LSTM层数（默认1）
- `--dropout`: Dropout比率（默认0.1）

##### 训练参数
- `--train`: 是否训练（默认False）
- `--actor_net_lr`: Actor网络学习率（默认1e-4）
- `--critic_net_lr`: Critic网络学习率（默认1e-4）
- `--random_seed`: 随机种子（默认5）
- `--max_grad_norm`: 梯度裁剪（默认2.0）
- `--decode_len`: 解码最大步数（默认30）

##### 评估参数
- `--sampling`: 是否进行批量采样（默认True）
- `--n_samples`: 批量采样数量（默认5）

#### `utils/agent.py`
- **功能**：A2C强化学习智能体
- **主要方法**：
  - `train()`: 训练方法
  - `test()`: 测试方法
  - `sampling_batch()`: 批量采样方法

#### `utils/env.py` 和 `utils/env_no_comb.py`
- **功能**：TSPD环境定义
- **作用**：
  - 定义状态空间和动作空间
  - 实现环境重置和状态转移
  - 计算奖励函数
  - 检查终止条件

#### `utils/utils.py`
- **功能**：通用工具函数
- **包含**：
  - 距离计算函数
  - 输出格式化函数
  - 数据预处理函数

### 3. 神经网络模型

#### `model/AttentionModel.py`
- **功能**：基于注意力的序列到序列模型
- **特点**：
  - 使用图注意力编码器
  - 支持批量处理
  - 实现贪心解码和采样解码

#### `model/graph_encoder.py`
- **功能**：图神经网络编码器
- **作用**：
  - 将节点特征编码为嵌入向量
  - 实现图注意力机制

#### `model/nnets.py`
- **功能**：Actor-Critic网络实现
- **包含**：
  - `Actor`: 策略网络
  - `Critic`: 价值网络

## 数据格式

### 输入数据格式
每行表示一个TSPD实例：
```
x_1 y_1 d_1 x_2 y_2 d_2 ... x_n y_n d_n
```

其中：
- `x_i, y_i`: 客户i的坐标
- `d_i`: 客户i的需求（客户需求为1.0，仓库需求为0.0）
- 最后一个节点为仓库

### 输出结果
- `logs/results.txt`: 训练和测试日志
- `results/`: 评估结果文件
- `solution_visualizations/`: 解决方案可视化图像

## 性能调优建议

### 1. 训练速度优化
- 使用GPU加速训练
- 适当增大batch_size
- 调整学习率

### 2. 模型性能优化
- 增加隐藏层维度
- 增加训练轮数
- 使用更好的随机种子

### 3. 内存优化
- 减小batch_size
- 减小隐藏层维度
- 使用梯度累积

## 常见问题解决

### 1. 内存不足
```bash
# 减小batch_size
python main.py --train=True --batch_size=32

# 减小隐藏层维度
python main.py --train=True --hidden_dim=128
```

### 2. 训练时间过长
```bash
# 减少训练轮数
python main.py --train=True --n_train=100000

# 使用预训练模型微调
python main.py --train=True --n_nodes=20 --n_train=50000
```

### 3. 结果不理想
- 检查参数设置
- 增加训练数据
- 调整网络结构
- 使用不同的随机种子
